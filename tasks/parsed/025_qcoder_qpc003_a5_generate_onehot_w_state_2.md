## 2. Условие задачи (Problem Statement)

### A5: Generate One-hot Superposition State II
* **Time Limit:** 3 seconds
* **Memory Limit:** 512 MiB
* **Score:** 200 points

#### Problem Statement
You are given an integer $n$.
Implement the operation of preparing the state $|\psi\rangle$ from the zero state on a quantum circuit $\mathrm{qc}$ with $n$ qubits.

The state $|\psi\rangle$ is defined as
\begin{equation}
\ket{\psi} = \frac{1}{\sqrt{n}} \lparen \ket{10...0}_n + \ket{010...0}_n + \cdots + \ket{0...01}_n \rparen \nonumber
\end{equation}.

#### Constraints
* $2 \le n \le 15$
* **The circuit depth must not exceed 20.**
* Global phase is ignored in judge.
* The submitted code must follow the specified format:
```python
from qiskit import QuantumCircuit


def solve(n: int) -> QuantumCircuit:
    qc = QuantumCircuit(n)
    # Write your code here:

    return qc
```

#### Sample Input
* $n = 4$:
  Implemented circuit $\mathrm{qc}$ should perform the following transformation:
  $$\ket{0000} \xrightarrow{\mathrm{qc}} \frac{1}{\sqrt{4}} (\ket{1000} + \ket{0100} + \ket{0010} + \ket{0001})$$

## 3. Анализ проверяющей системы (Auto-Judge)
* **Принцип проверки:**
  - Судья вызывает функцию `solve(n)` для набора тестовых значений $n \in [2, 15]$.
  - Проверяет корректность структуры `QuantumCircuit`: ровно $n$ кубитов, отсутствие операций измерения, строгое выполнение условия на глубину `qc.depth() <= 20`.
  - Выполняет симуляцию квантовой схемы на исходном состоянии $|0\rangle^{\otimes n}$ через вектор состояния (`Statevector`).
  - Сравнивает полученный вектор состояния $|\psi_{actual}\rangle$ с целевым состоянием $|W_n\rangle = \frac{1}{\sqrt{n}} \sum_{i=0}^{n-1} |2^i\rangle$ с точностью до глобальной фазы ($|\langle \psi_{target} | \psi_{actual} \rangle| \ge 1 - 10^{-7}$).
* **Каверзные случаи:**
  - *Ограничение глубины ($\le 20$):* Наивный линейный каскад последовательного отщепления амплитуды ($q_0 \to q_1 \to \dots \to q_{n-1}$) имеет глубину порядка $2(n-1) \approx 28$ при $n=15$, что приведет к превышению лимита. Необходимо использовать древовидное деление амплитуды (divide-and-conquer binary tree) с логарифмической глубиной $O(\log n) \le 10$ или оптимизированный каскад с параллельным исполнением неконфликтующих гейтов.
  - *Произвольные (нестепенные) $n$:* Требуется корректный расчет непрерывных углов вращения $\theta = 2 \arccos(\sqrt{k_L / (k_L + k_R)})$ для каждого узла деления амплитуды между левым ($k_L$) и правым ($k_R$) поддеревьями.
  - *Относительные фазы:* Все однобитные базисные состояния должны иметь одинаковую фазу. Любое появление паразитных фазовых сдвигов ($e^{i\phi_k}$) в управляемых вращениях разрушает целевое $W$-состояние.
  - *Симметрия базиса:* Базис one-hot состояний инвариантен к нумерации кубитов (little-endian vs big-endian), так как суммируются все базисные векторы веса Хэмминга 1.
* **Оценка числа тестов:** 14 тестов (полное покрытие диапазона $n = 2, 3, \dots, 15$, включая граничные $n=2, 15$ и степени двойки $n=4, 8$).
* **Асимптотика и быстродействие:**
  - Размерность пространства состояний: максимум $2^{15} = 32\,768$ комплексных амплитуд (~512 КБ).
  - Вычисление `Statevector` для схемы глубины $\le 20$ на 15 кубитах требует $\sim 10^5$ операций (единицы миллисекунд на тест).
  - Память симуляции: $O(2^n) \le 1$ МБ.
  - Суммарное время валидации полного набора тестов: $< 100$ мс (значительно ниже лимита 3.0 с).
