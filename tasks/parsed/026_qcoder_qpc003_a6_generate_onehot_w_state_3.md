## 2. Условие задачи (Problem Statement)

### A6: Generate One-hot Superposition State III
* **Time Limit:** 3 seconds
* **Memory Limit:** 512 MiB
* **Score:** 300 points

#### Problem Statement
You are given an integer $n$. Implement preparing $|\psi\rangle = \frac{1}{\sqrt{n}}(|10\dots 0\rangle + \dots + |0\dots 01\rangle)$ on `qc` with $n$ qubits.

#### Constraints
* $2 \le n \le 15$
* The circuit depth must not exceed 10.
* Global phase is ignored in judge.
* The submitted code must follow the specified format:
```python
from qiskit import QuantumCircuit

def solve(n: int) -> QuantumCircuit:
    qc = QuantumCircuit(n)
    # Write your code here:
    return qc
```

#### Sample Input / Output
* Sample 1: $n = 2$
  $$|00\rangle \xrightarrow{qc} \frac{1}{\sqrt{2}}(|10\rangle + |01\rangle) = |\Psi^+\rangle$$
* Sample 2: $n = 3$
  $$|000\rangle \xrightarrow{qc} \frac{1}{\sqrt{3}}(|100\rangle + |010\rangle + |001\rangle) = |W_3\rangle$$
