## 2. Условие задачи (Problem Statement)

### B4: Quantum Fourier Transform
* **Time Limit:** 3 seconds
* **Memory Limit:** 512 MiB
* **Score:** 200 points

#### Problem Statement
You are given an integer $n$. Implement the quantum Fourier transform (QFT) for $n$ qubits:
$$|j\rangle_n \to \frac{1}{\sqrt{2^n}} \sum_{k=0}^{2^n-1} \exp\left(\frac{2\pi i j k}{2^n}\right) |k\rangle_n.$$

#### Constraints
* $1 \le n \le 10$
* The circuit depth must not exceed 25.
* Integers are encoded in little-endian notation ($|100\rangle = 1$).
* [Global phase](https://www.qcoder.jp/en/qa#global) is ignored in judge.
* The submitted code must follow the specified format:
```python
from qiskit import QuantumCircuit

def solve(n: int) -> QuantumCircuit:
    qc = QuantumCircuit(n)
    # Write your code here:
    return qc
```

#### Sample Input / Output
$n=2$:
$$|10\rangle \to \frac{1}{2} \left(|00\rangle + e^{i\pi/2}|10\rangle + e^{i\pi}|01\rangle + e^{i 3\pi/2}|11\rangle\right)$$

## 3. Анализ проверяющей системы (Auto-Judge)
* **Принцип проверки:** Судья вызывает `solve(n)` для набора $n \in [1, 10]$, валидирует ограничения схемы (число кубитов ровно $n$, `qc.depth() <= 25`, отсутствие классических измерений и сбросов) и проверяет соответствие унитарной матрицы схемы эталонному дискретному преобразованию Фурье $F_n = \frac{1}{\sqrt{2^n}} \left( e^{2\pi i j k / 2^n} \right)_{j, k}$ с точностью до глобальной фазы.
* **Каверзные случаи:**
  - *Порядок кубитов (Bit-reversal / SWAP):* Стандартный каскад контролируемых фазовых вентилей формирует состояние в обратном порядке кубитов; обязательна корректная перестановка пар кубитов вентилями `SWAP` (или обратный порядок обхода индексов).
  - *Лимит глубины ($\le 25$):* Для $n=10$ общее число контролируемых фаз $\binom{10}{2} = 45$. При последовательном применении глубина может превысить лимит; необходима компактная укладка вентилей (глубина канонической параллелизованной схемы QFT для $n=10$ составляет $\sim 19$–$24 \le 25$).
  - *Точность непрерывных углов вращения:* Контролируемые фазовые сдвиги $CP(\theta_k)$ требуют углов $\theta_k = \frac{2\pi}{2^k} = \frac{\pi}{2^{k-1}}$.
* **Оценка числа тестов:** 10 тестовых запусков (все допустимые $n \in \{1, 2, \dots, 10\}$, включая граничные $n=1$ и $n=10$).
* **Асимптотика и быстродействие:** Сложность симуляции $O(2^n)$ по времени и памяти. При $n \le 10$ размерность вектора состояний $2^{10} = 1024$ (память $< 64$ КБ на тест), время валидации одной схемы $< 10$ мс, суммарное время проверки всех тестов $< 100$ мс.
* **Полная проверка без шотов и перебор:**
  - *Проверка без шотов:* **Да, 100%**. Аналитическая проверка через `Operator(qc)` / `Statevector` без использования стохастических измерений.
  - *Решаемость перебором:* **Защищена**. Наличие непрерывных углов фазовых сдвигов ($\pi/2^k$), факторизованная структура на $n=10$ кубитах и ограничение по глубине делают перебор невозможным.
