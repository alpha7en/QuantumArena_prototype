# sparq |arena⟩

Демо платформы квантовых задач: собираешь схему или пишешь код на Qiskit, система проверяет решение на симуляторе, по воскресеньям — раунды с рейтингом. Проект сообщества [SPARQ](https://t.me/sparqteam).

**Демо:** https://alpha7en.github.io/QuantumArena_prototype/

Это прототип. Сервера нет: схемы, проверка решений и аккаунт работают в вашем браузере, участники и результаты раундов смоделированы. Подробно — в [docs/DEMO_DATA.md](docs/DEMO_DATA.md).

## Что внутри

- **Банк задач** — 43 задачи от состояния Белла до кода Шора, шесть архетипов, три уровня сложности ([каталог](docs/TASK_CATALOG.md)).
- **Редактор задачи** — схема и код синхронны: перетаскивание гейтов, управляющие кубиты, диски вероятностей на проводах, формула состояния, измерения ×1024, лимиты задачи.
- **Тестирующая система** — каскад «ограничения → входы → шум»: глобальная фаза не мешает, относительные фазы между входами проверяются, вспомогательные кубиты обязаны вернуться в `|0⟩` ([как устроена](docs/JUDGE.md)).
- **Песочница** — свободная схема до 8 кубитов, примеры, режим «по шагам», разложение гейтов, ссылка на схему без сервера.
- **Раунды и рейтинг** — расписание, регистрация, таймер, штрафы, итоги, рейтинг участников и вузов (смоделированные данные).
- **Дизайн** — перенос макетов Figma «QuantumLeetCode» (тёмная и светлая темы), [соответствие](docs/DESIGN.md).

## Запуск

Сайт — статические файлы, сборка не нужна. Модули не работают по `file://`, поэтому нужен любой статический сервер:

```bash
python3 -m http.server 8080     # http://localhost:8080
npm test                        # проверка симулятора, интерпретатора, судьи и эталонов всех задач
```
