# Архитектура платформы и Квантовый симулятор

## 1. Общая платформа
* **Каталог задач:** фильтрация по сложности, квантовым темам (оракулы, синтез состояний, QEC) и типу схемы (фиксированная / параметризованная).
* **Рабочая область:** split-view с условием задачи (LaTeX), визуальным редактором схемы, редактором кода (Qiskit/Python) и панелью проверки.
* **Профиль:** ELO-рейтинг, процентили по числу гейтов и глубине, верифицированные бейджи для вузов и компаний.

---

## 2. Квантовый симулятор и Песочница
* **Песочница:** свободное конструирование квантовых цепей с мгновенным реактивным пересчетом вектора состояния на клиенте без кнопки «Run».
* **Эргономика UX:**
  * Перетаскивание гейтов из палитры на шины кубитов;
  * Удаление: клик по элементу (кнопка корзины) или перетаскивание за границы схемы (*drag-out to delete*).
* **Control Gates:** поддержка 1-control ($CX, CZ, CH$), multi-control ($CCX, MCX$) и negative control ($|0\rangle$).
* **Символьный CAS состояний:** распознавание базисов и алгебраическое сворачивание амплитуд в аналитическую LaTeX-формулу ($|\Phi^\pm\rangle, |\Psi^\pm\rangle, |+\rangle, |-\rangle, |GHZ\rangle, |W_3\rangle$).
* **3D Сфера Блоха:** трехмерное отображение вектора состояния кубита с расчетом редуцированной матрицы плотности $\rho_i = \text{Tr}_{\bar{i}}(|\psi\rangle\langle\psi|)$ (длина $|r| < 1$ при запутанности).
* **Формат данных:** внутренний легковесный JSON AST на клиенте + двунаправленный транспайлер в OpenQASM 3.0 и Python Qiskit.
* **Двусторонняя синхронизация:** Код $\leftrightarrow$ Графическая схема.

---

## 3. Режимы симулятора
* **Свободный режим:** открыты все гейты, неограниченный холст, функции экспорта.
* **Режим задачи:** блокировка палитры под разрешенный базис, отображение лимитов (бюджет гейтов, глубина, допустимый граф связности кубитов / coupling map), индикаторы выполнения условий и запрет неразрешенных связей.
