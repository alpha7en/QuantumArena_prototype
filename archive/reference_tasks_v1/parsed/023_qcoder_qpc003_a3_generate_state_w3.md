## 3. Анализ проверяющей системы (Auto-Judge)
* **Принцип проверки:** Судья вызывает функцию `solve()`, валидирует структуру `QuantumCircuit(3)` и симулирует эволюцию начального состояния $|000\rangle$ с помощью `Statevector` симулятора. Полученный вектор состояния $|\psi_{\text{gen}}\rangle$ сравнивается с целевым $|\psi_{\text{target}}\rangle = \frac{1}{\sqrt{3}}(|100\rangle + |010\rangle + |001\rangle)$ через вычисление точности (state fidelity $|\langle \psi_{\text{target}} | \psi_{\text{gen}} \rangle|^2 = 1.0$), что допускает произвольную глобальную фазу.
* **Каверзные случаи:**
  - *Неравномерность амплитуд / непрерывный угол вращения:* В отличие от состояний Белла и GHZ (где коэффициенты равны $1/\sqrt{2}$ и формируются дискретным гейтом $H$), 3-кубитное W-состояние требует разделения вероятности на 3 равные части ($1/3$). Для этого необходим поворот кубита на непрерывный угол $\theta = 2\arccos(1/\sqrt{3}) = 2\arcsin(\sqrt{2/3}) \approx 1.910633\text{ rad}$ с помощью гейта $Ry(\theta)$. Использование только дискретного базиса Клиффорда ($H, X, CX$) не способно точно сгенерировать амплитуду $1/\sqrt{3}$.
  - *Относительные фазы суперпозиции:* Все три компоненты $|100\rangle, |010\rangle, |001\rangle$ должны иметь нулевые относительные фазы (строго одинаковый фазовый множитель без комплексных или отрицательных фаз).
  - *Утечка в подпространства с иным весом Хэмминга:* Итоговый вектор должен находиться строго в одновозбужденном подпространстве (Hamming weight = 1) без паразитных амплитуд при $|000\rangle, |011\rangle, |101\rangle, |110\rangle, |111\rangle$.
  - *Когерентность и отсутствие измерений:* Схема должна выполнять унитарное преобразование без промежуточных измерений, схлопывающих суперпозицию.
* **Оценка числа тестов:** 1 тест (проверка итогового вектора состояния на входе $|000\rangle$).
* **Асимптотика и быстродействие:** Размерность гильбертова пространства $2^3 = 8$. Временная и емкостная сложность $O(2^3) = O(1)$ (< 1 КБ памяти). Время исполнения проверки: < 5 мс.
* **Полная проверка без шотов и перебор:**
  - *Проверка без шотов:* **Да, 100%**. Аналитическая проверка через `Statevector` симуляцию без стохастического шума измерений.
  - *Решаемость перебором:* **Затруднена дискретным перебором (требуется непрерывный угол)**. Простой перебор по дискретной решетке гейтов Клиффорда+$T$ не дает точного решения. Однако при параметризации одного угла $\theta \in [0, 2\pi]$ и переборе топологии из 3–5 гейтов ($Ry, CX, CH, X$) решение находится гибридным перебором/оптимизацией за секунды.
