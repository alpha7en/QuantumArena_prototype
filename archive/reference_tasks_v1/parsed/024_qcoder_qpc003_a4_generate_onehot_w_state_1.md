## 2. Условие задачи (Problem Statement)

### A4: Generate One-hot Superposition State I
* **Time Limit:** 3 seconds
* **Memory Limit:** 512 MiB
* **Score:** 200 points

#### Problem Statement
You are given an integer $n$.
Implement the operation of preparing the state $|\psi\rangle$ from the zero state on a quantum circuit $\mathrm{qc}$ with $n$ qubits.

The state $|\psi\rangle$ is defined as
$$|\psi\rangle = \frac{1}{\sqrt{n}}(|10...0\rangle + |010...0\rangle + \dots + |0...01\rangle).$$

#### Constraints
* $2 \le n \le 15$
* [Global phase](https://www.qcoder.jp/en/qa#global) is ignored in judge.
* The submitted code must follow the specified format:
```python
from qiskit import QuantumCircuit

def solve(n: int) -> QuantumCircuit:
    qc = QuantumCircuit(n)
    # Write your code here:
    return qc
```

#### Sample Input / Output
* Sample 1: $n = 4$
  $$|0000\rangle \xrightarrow{\mathrm{qc}} \frac{1}{\sqrt{4}}(|1000\rangle + |0100\rangle + |0010\rangle + |0001\rangle) = \frac{1}{2}(|1000\rangle + |0100\rangle + |0010\rangle + |0001\rangle)$$

* **Каверзные случаи:**
  - *Непрерывные углы вращения:* В отличие от состояний Белла или GHZ, где достаточно дискретных гейтов Адамара ($H$), для произвольного $n$ требуется точный расчет непрерывных углов вращений $R_y(\theta)$ на каждом шаге каскада (например, $\theta_k = 2\arccos\sqrt{\frac{1}{n-k}}$ или $\theta_k = 2\arcsin\sqrt{\frac{1}{n-k}}$ для отщепления $1/(n-k)$ доли вероятности).
  - *Отсутствие ограничений на глубину:* В отличие от версий задачи A5 ($\text{depth} \le 20$) и A6 ($\text{depth} \le 10$), в A1–A4 допустим простой линейный каскад глубиной $O(n)$ с последовательным переносом возбуждения ($q_0 \to q_1 \to \dots \to q_{n-1}$), не требующий построения сбалансированного бинарного дерева.
  - *Относительные фазы:* Все $n$ базисных состояний $|10\dots 0\rangle, |010\dots 0\rangle, \dots$ должны иметь строго одинаковую фазу. Появление паразитных фазовых сдвигов ($e^{i\phi}$) в контролируемых вращениях разрушает состояние.
  - *Симметрия базиса (Little-endian vs Big-endian):* Состояние $W_n$ полностью симметрично относительно перестановки кубитов, поэтому вектор состояния инвариантен к соглашению о порядке следования битов.
  - *Утечка из одночастичного подпространства:* Схема должна строго сохранять суммарный вес Хэмминга равным 1 (амплитуды при $|0\dots 0\rangle$ и состояниях с $\ge 2$ единицами должны быть строго равны 0).
