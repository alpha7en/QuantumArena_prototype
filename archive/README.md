# Архив

Материалы первой версии прототипа и справочные документы. Новый сайт их не использует.

| Путь | Что это |
|------|---------|
| `prototype_v1.html` | первая версия прототипа (один файл, светлая тема); открывается локально |
| `canvas/` | интерактивная схема дорожной карты (Obsidian Canvas и HTML) |
| `docs_v1/` | первая версия документации: архитектура, судья и безопасность, открытые вопросы, гранты |
| `reference_tasks_v1/` | 43 разобранные чужие задачи (QCoder, IBM Challenge) — образцы для методики, на платформу не переносятся |

Актуальная документация — в [`../docs`](../docs).
