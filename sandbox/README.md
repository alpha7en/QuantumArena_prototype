# Песочница sparq arena — новая версия

Редактор квантовых схем: схема и код Qiskit синхронны в обе стороны, результат считается в браузере.
Это отлаженная версия кликабельного прототипа (макеты Figma 00–11, спецификация от 15 ноября 2026).
Старая песочница демо (`#/sandbox` на главном сайте) пока не тронута; эта версия живёт отдельно и
предназначена для переноса на платформу.

**Открыть:** `sandbox/` на GitHub Pages — https://alpha7en.github.io/QuantumArena_prototype/sandbox/ ·
режим задачи — `sandbox/?task=demo`.

```bash
python3 -m http.server 8080     # http://localhost:8080/sandbox/
npm test                        # в том числе tests/sandbox.test.mjs — 17 тестов ядра
```

## Файлы

| Файл | Что в нём |
|---|---|
| `index.html` | разметка экрана: навигация, панель проекта, левое меню, палитра, центр, результат |
| `sandbox.css` | стили прототипа на токенах `qlc/dark` и `qlc/light` плюс дополнения |
| `js/core.js` | ядро без DOM: модель схемы, разбор Qiskit, генерация кода, симуляция, ресурсы, разложения, контракт задачи |
| `js/app.js` | интерфейс: отрисовка, перетаскивание, проекты, блоки, окна, режим задачи |
| `js/examples.js` | примеры, шаблоны блоков, демонстрационная задача |

Шрифты берутся из `../assets/fonts` — внешних запросов нет.

## Что умеет

- **Схема ↔ код.** Правка кода через 0,4 с перестраивает схему; правка схемы сразу переписывает код.
  Поддержаны `for`, `if`/`else`, `def` с параметрами и вложенными вызовами, `measure` в выбранный
  классический бит, `reset`, `barrier`, условие `with qc.if_test((qc.clbits[k], v)):` и старое
  `.c_if(k, v)`, цикл `with qc.while_loop((qc.clbits[k], v)):`, многоконтрольные `ccz`, `mcx`, `mcp`.
- **Симуляция с измерениями.** Вектор состояния с ветвлением по исходам: после измерения состояние —
  смесь, условные гейты и `while` считаются точно. До 8 кубитов.
- **Результат.** Вероятности, амплитуды (по исходам измерений), сфера Блоха, матрица плотности или
  унитарная, стабилизаторы, оценка шума. Срез по любому столбцу. Запуск ×N даёт отсчёты по
  классическим битам, как в Qiskit; если измерений нет — по всем кубитам.
- **Наборы гейтов.** Стандартный, Clifford, Clifford + T, IBM Heron. Гейты вне набора подсвечены
  (в том числе внутри блоков), их можно разложить на гейты набора из панели гейта.
- **Блоки.** Функция `def` = блок на схеме. Редактор блока: код или схема, параметры сохраняются.
- **Проекты.** Хранятся в браузере (`localStorage`), автосохранение, версии, переименование, удаление.
  Примеры открываются как копии. «Поделиться» — ссылка, в которой записана сама схема.
- **Экспорт.** OpenQASM 3 и 2, Qiskit, PennyLane, Cirq, JSON SPARQ, SVG, LaTeX (quantikz) — копировать
  или скачать файлом.
- **Режим задачи.** `?task=…` задаёт число кубитов, набор гейтов и лимиты; панель показывает лимиты
  вживую; «отправить» передаёт решение странице задачи.

## Договорённости, общие с проверяющей системой

- Порядок кубитов — как в Qiskit: кубит $i$ — бит $i$ числа, $q_0$ младший.
- Ресурсы считает `metrics()` в `js/core.js` по тем же определениям, что `bank/tools/sakit.py`:
  гейты — без измерений, сброса и барьеров; глубина — при самой ранней расстановке, барьеры не
  считаются; блоки и тела циклов раскрываются; многокубитный гейт — гейт на двух и более кубитах.
- Формат передачи схемы — JSON SPARQ (`genJson`): `{ format: "sparq-circuit", version: 1, qubits,
  clbits, ops: [{ g, q, c?, p?, cb?, cond?, col }] }`.

## Режим задачи: как страница задачи подключает песочницу

Песочница открывается в `<iframe>` (или отдельной вкладкой) с параметром `task` — JSON в base64url:

```json
{
  "id": "SA-001@1", "code": "SA-001", "title": "Состояние Белла со знаком минус",
  "url": "https://…/tasks/SA-001",
  "qubits": 2, "clbits": 0,
  "allow": ["H", "X", "Z", "CX"],
  "limits": { "gates": 3, "depth": 3 },
  "initial": "необязательный стартовый код Qiskit"
}
```

То же можно передать сообщением `postMessage({ type: "sparq:task", task })` после загрузки.
В режиме задачи: число кубитов и набор гейтов заблокированы, проекты и «поделиться» скрыты,
черновик хранится отдельно по `id` задачи. Кнопка «отправить» шлёт родительскому окну

```js
{ type: "sparq:submit", taskId, format: "sparq-circuit", circuit: {…}, qiskit: "…", metrics: {…} }
```

Ответ `postMessage({ type: "sparq:verdict", verdict: "…" })` показывается участнику. Песочница
проверяет только открытые ограничения (лимиты, набор гейтов, число кубитов). Скрытых тестов в ней
нет и быть не должно: вердикт выносит сервер.

Виды гейтов для `allow`: `H X Y Z S Sdg T Tdg SX RX RY RZ P CX CZ CY CH CP CCX CCZ MCX MCZ MCP SWAP M R BAR`.

## Что было не так в прототипе и что исправлено

Разбор исходного `sandbox.html` (один файл, 1100 строк). Нумерация — для ссылок из задач.

### Ошибки, из-за которых результат был неверным

| № | Проблема | Что сделано |
|---|---|---|
| 1 | Измерение не влияло на состояние: гейты после него считались так, будто его нет | симуляция с ветвлением по исходам; диски, Блох и матрица показывают смесь |
| 2 | Тело `while_loop` при расчёте выбрасывалось, а `qc.reset` парсер не знал: пример «телепортация» не открывался | `reset` и `while_loop` разбираются и считаются (до 64 итераций, остаток вероятности показывается предупреждением) |
| 3 | `qc.measure(q, c)` теряло номер бита; запуск выдавал отсчёты по всем кубитам, даже если измерен один | у измерения есть бит назначения; запуск считает распределение классического регистра |
| 4 | Условных гейтов не было ни в коде, ни на схеме | `if_test`, `c_if`, выбор условия в панели гейта, отрисовка связи с классическим проводом |
| 5 | «Глубина» равнялась числу столбцов на экране, блок считался за 2 CX, «CX-экв.» — по выдуманным весам | `metrics()` по определениям проверяющей системы, блоки раскрываются |
| 6 | Шум во вкладке и в запуске считался по разным формулам, ошибка считывания в запуск не попадала | одна функция для обоих мест |
| 7 | Время запуска измерялось после расчёта и всегда было «3 мс»; отсчёты прошлого запуска оставались под новой схемой | настоящее время; после правки схемы результат помечается устаревшим |
| 8 | Стабилизаторы отключались по списку «неклиффордовых» гейтов: $R_z(\pi/2)$ считался запрещённым, блок — всегда | проверяется само состояние; после измерения — честное сообщение о смеси |
| 9 | Чистота $\operatorname{Tr}\rho^2$ была вписана константой `1,00`; унитарной матрицы, заявленной в спецификации, не было | чистота считается; добавлен вид «унитарная $U$» |

### Что осталось и уходит в требования к платформе

1. **Правка схемы разворачивает `for`.** Схема хранит цикл развёрнутым, поэтому любая правка мышью
   переписывает код без цикла, а комментарии в коде теряются. Нужна правка текста по месту
   (изменить одну строку, а не весь файл).
2. **Обратный перевод только из Qiskit.** OpenQASM 3, PennyLane и Cirq — только для чтения.
3. **Сервер.** Вариант «на сервере» в настройках запуска — надпись. Короткие ссылки, проекты в
   аккаунте, общие блоки курса требуют бэкенда.
4. **Шум** — оценка порядка величины (деполяризация всей схемы), не моделирование по гейтам.
5. **Клавиатура.** Гейт можно выбрать с клавиатуры, но поставить на клетку — только мышью или касанием.
6. **Узкий экран.** На телефоне панели складываются в столбец; перетаскивание работает, но раскладка
   не проектировалась (мобильных макетов нет).
7. **Условие по одному биту.** Условие по нескольким битам или по значению регистра не поддержано.
8. **Положение по столбцам** не хранится в проекте: после перезагрузки гейты встают как можно левее.
