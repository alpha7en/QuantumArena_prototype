# Архитектура демо

Статический сайт без сборки: HTML, CSS и ES-модули. Сервера нет, все вычисления идут в браузере. Подходит для GitHub Pages «как есть».

```
index.html                     оболочка: шапка, #app, подвал
assets/
  css/        tokens · base · components · pages · editor      (токены из Figma, светлая и тёмная темы)
  fonts/      Unbounded · Onest · JetBrains Mono (woff2, OFL)  (подключены локально, внешних запросов нет)
  js/
    app.js            маршруты, шапка, баннер «демо»
    router.js         маршрутизатор на хэше (#/tasks/1)
    store.js          localStorage: аккаунты, прогресс, раунды, настройки
    quantum/          gates · sim (вектор) · dm (матрица плотности, шум) · circuit · format
    lang/             pyinterp (подмножество Python) · qiskitlite (QuantumCircuit и генерация кода)
    judge/            judge (каскад проверок) · builders (конструкторы наборов тестов)
    data/             tasks (банк) · people (смоделированные участники) · rounds · roundstate · demo
    ui/               board (SVG-доска схемы) · taskeditor · codeeditor · parts · chrome · overlay · icons · dom
    pages/            home · tasks · task · contests · round · roundtask · rating · university · profile · settings · sandbox · learn · auth
tests/                node:test — симулятор, интерпретатор, судья, эталоны всех задач
scripts/              gen_catalog.mjs — каталог задач из кода
docs/                 документация
archive/              первая версия прототипа и справочные материалы
```

## Поток данных

1. `router.js` по хэшу находит модуль страницы и вызывает `default(ctx)`; страница возвращает `{ title, nav, layout, html, mount, unmount }`.
2. `app.js` вставляет `html`, перерисовывает шапку и вызывает `mount(root)`.
3. Редактор (`taskeditor.js`) держит модель схемы (`Circuit`) или код. Любое изменение → `refresh()`: построение схемы (в режиме кода — выполнение интерпретатором), симуляция вектора состояния, проверка лимитов, перерисовка холста и нижней панели.
4. «Отправить» → `judge(task, build, { noise })` → вердикт → запись в `store` (отправки, решённые, серия, активность, уведомления) → при раунде `roundstate.onVerdict` обновляет прогресс и штраф.

## Хранилище

Один ключ `sparq-arena:v2` в `localStorage`:

| Раздел | Содержимое |
|--------|------------|
| `accounts` | локальные аккаунты (пароль — SHA-256 с солью, только имитация входа) |
| `session` | id текущего аккаунта |
| `data[id]` | решённые задачи, попытки, отправки, черновики схем и кода, раунды, рейтинг и его история, уведомления, активность, серия, настройки, черновик песочницы |
| `data.guest` | то же для гостя; при регистрации переносится в аккаунт |
| `ui` | тема, скрытый баннер |

Если `localStorage` недоступен, сайт работает на данных в памяти до закрытия вкладки.

## Модуль схемы

`Circuit { n, ops[] }`, операция — `{ g, t[], c[], p[], col }`: базовый гейт `g`, целевые кубиты `t`, управляющие `c`, параметры `p`, столбец `col` для раскладки. Кубит `k` — бит `k` индекса базисного состояния (порядок как в Qiskit). Глубина — число ASAP-слоёв, считается по реально задействованным кубитам. Раскладка по столбцам запрещает перекрытие диапазонов «от верхнего до нижнего кубита».

## Границы по ресурсам

| Что | Предел |
|-----|--------|
| Кубитов в схеме | 12 в коде, 8 в песочнице |
| Операций | 5000 |
| Шагов интерпретатора | 1,5 млн на запуск |
| Матрица плотности (шум) | до 7 кубитов |
| Набор тестов | до 64 базисных входов + 3 случайных суперпозиции на задачу |

## Безопасность

Пользовательский код не исполняется напрямую: нет `eval`, `Function`, доступа к `window`/DOM; интерпретатор работает с собственным AST. Страницы строят HTML из экранированных значений (`html` в `ui/dom.js`). Тесты и эталонные решения публичны — это демо, а не защищённый судья.

## Ссылки на состояние

- Схема песочницы кодируется прямо в адресе (`#/sandbox?c=…`, base64url от JSON) — делиться можно без сервера.
- Раунды: `rounds[n].run` хранит прогресс (минуты решения и неверные попытки), по нему считаются место и рейтинг.
