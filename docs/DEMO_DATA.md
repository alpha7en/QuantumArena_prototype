# Что в демо настоящее, а что смоделировано

Демо — прототип интерфейса и проверки решений. Серверной части нет. Этот документ нужен, чтобы никто не принял смоделированные цифры за реальные.

## Настоящее

| Что | Как работает |
|-----|--------------|
| Симулятор | Вектор состояния и матрица плотности, считаются в браузере |
| Проверка решений | Каскад из [JUDGE.md](JUDGE.md): ограничения, набор входов, шум |
| Банк задач | 37 задач с эталонами и тестами, [каталог](TASK_CATALOG.md) |
| Редактор схем и код | Перетаскивание, управляющие кубиты, по шагам, измерения ×1024, разложение; код Qiskit-lite синхронизирован со схемой |
| Аккаунт, прогресс, серия, активность | Локально, в `localStorage` этого браузера |
| Раунды | Запуск «демо-раунда» на 90 минут, штрафы за неверные отправки, итоги и пересчёт рейтинга по формуле ниже |

## Смоделировано

| Что | Как получено |
|-----|--------------|
| Участники, их имена, вузы, рейтинги | Генератор со стабильным seed (`assets/js/data/people.js`): 1 800 вымышленных участников, нормальное распределение рейтинга. Совпадения имён с реальными людьми случайны |
| Таблицы раундов, места, «решили N из M» | Модель вероятности решения от рейтинга участника и сложности задачи (`assets/js/data/rounds.js`); «играет» вместе с вашим таймером |
| Рейтинг вузов | Сумма рейтингов десяти лучших вымышленных студентов вуза. Названия вузов реальны, результаты — нет |
| «Решаемость» задач | Смоделированная доля решивших по уровню сложности |
| Счётчик «записались на раунд» | Расчётная величина от числа участников раунда |
| Расписание | Раунды по воскресеньям, 12:00 мск, 90 минут; номера считаются от раунда 522 (11.10.2026). В демо раунд запускается вручную |
| Демо-профиль | Заполненный пример с историей: кнопка на странице входа |

## Чего нет

Реального сервера, общих рейтингов, проверки на реальном квантовом железе, вопросов по безопасности для публичного соревнования (античит, изоляция чужого кода), писем и уведомлений вне браузера. Вход через Яндекс ID и VK ID не работает.

## Формулы

**Рейтинг.** После завершённого демо-раунда: `Δ = K · (p − E)`, где `p = 1 − (место − 1) / (N − 1)` — доля обойдённых участников, `E = 1 / (1 + 10^((1330 − R) / 400))` — ожидаемая доля при рейтинге `R`, `K = 90` для первых трёх раундов, `56` до восьмого, затем `36`. Начальное значение до первого раунда — `1200`. Раунды «с таймером» рейтинг не меняют.

**Титулы.** новичок < 1200, ученик 1200, специалист 1400, эксперт 1700, мастер 2000, гроссмейстер 2400+.

**Результат раунда.** Баллы за решённые задачи (100 / 200 / 200 / 300), при равенстве — меньшее время; время = минуты до принятия + 5 минут за каждую неверную отправку до принятия. Ошибка в коде (код не выполнился) штрафа не даёт.

**Шум в раундах.** Деполяризующий, ε = 1 % на двухкубитные гейты (см. [JUDGE.md](JUDGE.md)).

## Данные пользователя

Всё лежит в ключе `sparq-arena:v2` в `localStorage`. Пароль хранится хэшем SHA-256 с солью — это имитация входа, а не защита. В «Настройках → редактор» есть выгрузка данных в JSON и очистка черновиков; «удалить аккаунт» стирает аккаунт из браузера. Чтобы сбросить всё, достаточно очистить данные сайта в браузере.
