# Что сделано и что дальше

## В этой версии (демо v2)

- Полный перенос дизайна из Figma («QuantumLeetCode», страница «arena · прототип»): главная, банк задач, редактор задачи, песочница, контесты и раунды, рейтинг участников и вузов, профиль, настройки, вход и регистрация, обучение; тёмная и светлая темы.
- Квантовый симулятор (вектор состояния и матрица плотности) и интерпретатор Qiskit-lite — всё в браузере.
- Новая тестирующая система: каскад «ограничения → входы → шум», строгая проверка анцилл, согласование фаз между входами ([JUDGE.md](JUDGE.md)).
- Банк из 37 задач с эталонами ([TASK_CATALOG.md](TASK_CATALOG.md)), проверяемый автотестами.
- Демо-раунды с таймером, штрафами, итогами и пересчётом рейтинга; смоделированные участники.
- Документация: [ARCHITECTURE](ARCHITECTURE.md), [JUDGE](JUDGE.md), [TASKS](TASKS.md), [DESIGN](DESIGN.md), [DEMO_DATA](DEMO_DATA.md), [DEPLOY](DEPLOY.md), [DEVELOPMENT](DEVELOPMENT.md).

## Ограничения демо

| Ограничение | Следствие |
|-------------|-----------|
| Нет сервера | Тесты публичны, рейтинги и участники смоделированы, аккаунт живёт в одном браузере |
| Только численная симуляция | Проверка до ~12 кубитов; символьная эквивалентность (ZX, QCEC) не реализована |
| Динамические схемы | Классическое управление (`c_if`) не поддерживается, телепортация собирается через отложенное измерение |
| Задачи не прошли ревью | Условия и эталоны составлены при разработке прототипа; второй эксперт их вслепую не решал |
| Доска схем | Гейты на доске выбираются указателем; полноценная работа с доской с клавиатуры не сделана |
| Мобильная версия | В Figma не нарисована; сделана адаптивная вёрстка без отдельного дизайна |

## Дальше

1. **Ревью задач.** Каждую задачу решает вслепую второй участник команды, затем бета на участниках сообщества; правка условий и лимитов по итогам.
2. **Серверная проверка.** Вынести судью с тестами на сервер: изолированное исполнение чужого кода, хранение закрытых тестов, лимиты по времени и памяти. Интерфейс уже отделён от судьи (`judge(task, build, opts)`).
3. **Реальные аккаунты и раунды.** Общий рейтинг, расписание, регистрация, общая таблица вживую.
4. **Расширение проверки.** Заимствованные («грязные») анциллы, динамические схемы, символьные методы для больших `n`; результаты — в научную часть (исследования в `research/06_quantum_autograder_research`).
5. **Банк задач.** Расширение по матрице уровней, отдельные треки (коррекция ошибок, оптимизация под железо), задачи на открытый оптимум.
6. **Доступность и мобильная версия.** Клавиатурное управление доской, отдельный мобильный дизайн.
