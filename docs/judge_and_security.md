# Проверяющая система (Auto-Judge) и Безопасность

## 1. Архитектура проверки
* **Клиентский контур (WASM / JS):** задачи до 6–8 кубитов и открытые тесты; моментальный отклик ($<50$ мс) без нагрузки на сервер.
* **Серверный контур (Docker + gVisor):** закрытые олимпиадные тесты, тяжелые задачи ($n > 8$) и динамические цепи.
* **Критерии корректности:**
  * Аналитическая проверка Statevector Fidelity: $F = |\langle \psi_{target} | \psi_{actual} \rangle|^2 \ge 1 - \varepsilon$;
  * Операторная точность $F_{op} = \frac{1}{d}|\text{Tr}(U^\dagger_{target} U_{actual})| = 1.0$;
  * Статистическая проверка (Shots + $\chi^2$-критерий) для схем с измерениями.

---

## 2. Трехуровневая модель безопасности

### Уровень 1: Защита инфраструктуры (RCE & Host)
* Изоляция в gVisor (`runsc`), отключение сети (`--net none`), read-only rootfs;
* Ограничения cgroups: 2 ядра CPU, 512 МБ RAM, таймаут 5.0 с;
* AST-фильтрация: запрет `os`, `sys`, `subprocess`, `eval`, `exec`, `open`, `__import__`.

### Уровень 2: Защита от абьюза API Qiskit
* Блокировка интроспекции фреймов стека (`sys._getframe`, `inspect`);
* Запрет подмены бэкендов симулятора и переопределения служебных методов `QuantumCircuit`.

### Уровень 3: Защита от автоматического синтеза (Anti-Auto-Synthesis)
* **Проблема:** сдача решений через встроенные методы декомпозиции `qiskit.synthesis` или `decompose()` без реального решения алгоритма.
* **Методы детекции:**
  1. *Анализ углов:* наличие непрерывных машинных углов ($\theta = 1.234567\dots$) вместо дискретных фаз;
  2. *Сигнатуры KAK/Shannon:* совпадение топологии цепи со стандартными шаблонами синтеза Qiskit;
  3. *AST-бан:* запрет пакетов `qiskit.synthesis` и `scipy.linalg`;
  4. *Масштабирование тестов ($n=2\dots10$):* численные синтезаторы матриц $2^n \times 2^n$ падают по памяти и таймауту на больших $n$.

## 3. UX умных ограничений
* Отказ от длинных портянок запретов в пользу **позитивных контрактов**: формулируются только требования к задаче (разрешенный базис, лимит на гейты и глубину).
* Лаконичные сообщения об ошибках: `GateBudgetExceeded`, `RestrictedGateUsed`.
