# Публикация на GitHub Pages

Сайт — статические файлы, сборка не нужна.

## Один раз

1. Репозиторий → **Settings → Pages**.
2. **Source:** `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Адрес: `https://<пользователь>.github.io/<репозиторий>/` (для этого репозитория — `https://alpha7en.github.io/QuantumArena_prototype/`).

В корне лежит пустой файл `.nojekyll`, чтобы GitHub не обрабатывал файлы Jekyll'ом.

## Обновление сайта

```bash
npm test                         # эталоны и судья должны проходить
node scripts/gen_catalog.mjs     # обновить docs/TASK_CATALOG.md, если менялись задачи
git add -A && git commit -m "..." && git push origin main
```

Через минуту-две Pages обновит сайт. Маршруты сайта — на хэше (`#/tasks/1`), поэтому настройка перенаправлений для SPA не нужна; прямые ссылки на вложенные страницы работают.

## Локально

ES-модули не работают по `file://`, поэтому нужен любой статический сервер:

```bash
python3 -m http.server 8080      # затем открыть http://localhost:8080
```

## Проверка перед публикацией

- `npm test` — все тесты зелёные.
- Открыть главную, `#/tasks/1`, `#/sandbox`, `#/contests` и убедиться, что в консоли браузера нет ошибок.
- Переключить тему (аватар → тема) и проверить, что страницы читаются в обеих.
